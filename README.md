<h1 align="center">Python - Flask Introduction</h1>

**Description**: Introduction to Flask.

**Stack**:

- Python 3.12
- Flask 2.3.0
- Flask-SQLAlchemy
- Flask-Cors
- Werkzeug

## Getting started

Follow step by step below to execute this project correctly:

```SH
# initialize venv
python3 -m venv .venv
source .venv/bin/activate
# Install Python packages on the project
pip3 install -r requirements.txt
```
